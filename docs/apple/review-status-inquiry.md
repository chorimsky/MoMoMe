## Why it is phrased this way

It asks **one** question — queued, or blocked? — and gives the identifiers needed to answer it
without a reply asking for them. It raises the DSA gap rather than waiting to be told, which
costs nothing if that is not the cause and saves a round trip if it is. It does not ask for an
expedited review: that is a separate request, it is rationed, and spending it before knowing
whether the submission is merely queued would waste it.
